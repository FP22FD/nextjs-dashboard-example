# Next.js Routing Tutorial

- `pages/` for file-based routing (Next.js < 13).
- `app/` directory for new routing structure (Next.js 13+).
- Use `Link` from 'next/link' for client-side navigation.
- API routes live in `pages/api/` or `app/api/`.
- Dynamic routes: `[param].tsx` and optional `[...param].tsx`.
- Keep routes clean and consistent; follow REST conventions for API routes.
