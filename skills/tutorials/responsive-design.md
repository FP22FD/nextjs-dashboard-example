# Responsive Design with Tailwind

- Use `sm:`, `md:`, `lg:`, `xl:` for breakpoints.
- Flex and grid layouts for structure.
- Mobile-first approach: define mobile styles first, then add breakpoints.
- Test on multiple devices or browser dev tools.
- Use `container` class for consistent widths.
- Avoid fixed widths; prefer `max-w-*` classes.
